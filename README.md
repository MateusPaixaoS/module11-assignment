# Module 11 – Data Visualization with Matplotlib

This repository contains my work for Module 11 of the course.

## Project Overview

This project builds a full set of **data visualizations** for SunCoast Retail, a multi-location retailer operating across Tampa, Miami, Orlando, and Jacksonville. Using randomly generated but realistic sales and customer data, the script produces over a dozen charts and a summary business dashboard.

## Files Included

- `module11-assignment.py` – Main Python script containing data generation, all visualization functions, and key business insights.

## What I Practiced

- Creating line charts to display trends over time (quarterly sales, ad efficiency).
- Building grouped and stacked bar charts to compare performance across locations and categories.
- Generating scatter plots to explore relationships between variables (ad spend vs. sales).
- Using histograms and box plots to analyze customer age and purchase amount distributions.
- Designing pie charts to show market share and revenue composition.
- Combining multiple charts into a single business dashboard using Matplotlib subplots.
- Deriving and communicating key business insights from visual analysis.
